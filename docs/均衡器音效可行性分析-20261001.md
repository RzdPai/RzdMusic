# 均衡器与音效：仅分析，不实施

## 结论
可做，但必须分两档。

### 低成本：系统音效开关
当前 MediaService 是 AVPlayer URL/fdSrc backend。AVPlayer.audioEffectMode API10仅EFFECT_NONE(关闭)/EFFECT_DEFAULT(默认)。现在默认就是DEFAULT，不能包装成流行/摇滚/10段EQ，也不能保证切开一定听感变化。合法prepared/playing/paused/completed，推荐stateCall prepared且startPlayback前应用偏好；usage改变回DEFAULT，重prepare/重建需重应用。无新OHPM/专门EQ权限，现AudioKit/MediaKit即可。
官方：https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-media-avplayer
枚举：https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-audio-e#audioeffectmode10

### 中高成本：真正10段EQ与音效
不是鸿蒙没有EQ。正式AudioKit OHAudioSuite API22就有10段均衡器，31/62/125/250/500/1000/2000/4000/8000/16000Hz、每段[-10,+10]dB，9预设（默认/民谣/中国风/古典/舞曲/爵士/流行/R&B/摇滚）。API23+实时管线支持其它效果。当前defaultAPI24、pc最低API23满足，不需升级API26。
官方：https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/audio-suite-effects
https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/audio-suite-real-time-rendering
https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-native-audio-suite-engine-h

但是AudioSuite是C/C++ PCM管线，不是AVPlayer.setEqualizer，也不是AudioRenderer直接调频段。需要解封装/解码→PCM→AudioSuite/DSP→OH_AudioRenderer；回调AudioRendererOnWriteData内调用RenderFrame。依赖系统 libohaudio.so+libohaudiosuite.so（不是随便引入不存在Kit）；检查IsNodeTypeSupported。API26前最多1实时管线，运行中不得重建效果节点，参数更新有实时预算。

## 当前工程与改造边界
入口 features/player/src/main/ets/model/MediaService.ets；initAudioPlayer/createAVPlayer、loadCurrentIntoPlayer url/fdSrc、stateCall prepared，单例AVSession play/pause/next/previous/seek。EQ不能由设置页另建播放器；如立项保MediaService facade/MusicAppState/PlaybackIntent唯一真源，增加两个backend：可解码非DRM走PCM EQ，受保护/不支持空间流回AVPlayer。共享AVSession/后台任务和统一position/duration/EOF/seek/路由/interrupt。

先做非DRM本地文件，再可解码网络源。网络需Range/seek、headers/token过期、cache、弱网重连、容器/HLS、加载世代隔离、ringbuffer背压；实时线程不做网络/磁盘/大量分配/高频日志。EQ需headroom/preamp防削波和参数平滑；48k处理可能重采HiRes，必须显示真实解码/处理/输出规格，平台hires/atmos/master标签不证明保留无损或空间元数据。DRM不得内录绕过；Atmos/AudioVivid对象流转普通PCM可能丢空间信息，不能承诺原样保留。

AudioRenderer仅支持PCM等规格受设备影响：https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/audio-kit-intro
https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/using-audiorenderer-for-playback

## 不推荐猜测路线
本次官方和本机SDK未检出API24公开AudioEnhanceKit，不当生产依赖（不是断言所有平台永不存在）。AudioDeviceEnhanceManager是API26设备路由增强不是EQ；AudioLoopback EqualizerPreset是录音返听不是普通音乐播放器。

## 推荐
若只想开关系统处理，轻量接AVPlayer即可，诚实命名；若要10段滑杆/预设，独立立项正式AudioSuite双backend，先本地后网络。手机/平板/PC及扬声器/有线/蓝牙/USB分别验功耗、采样率、underrun、后台锁屏及长时稳定。

验证等级：官方文档级+源码只读分析，未修改音效代码、未添加依赖权限、无设备听感验证。
