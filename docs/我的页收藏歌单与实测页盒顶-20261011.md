### 1.2 我的页歌单不显示封面 → 封面优先级与「全部歌单」页对齐

**原因**：`MinePage.PlaylistRow` 只有两级 —— ① 自定义封面（`item.cover`）② 灰底音符占位，
注释还写着"不用第一首歌的封面顶替"。而 `PlaylistsPage.PlaylistRow` 是**三级**：
① 自定义封面 → ② **第一首歌的专辑图 `songs[0].img`** → ③ 占位。
两级列表口径不一致 ⇒ 只有"设过自定义封面"的歌单在我的页才有图。

**改法**：把 `PlaylistsPage` 那三级原样搬到 `MinePage.PlaylistRow`（`ROW_COVER=46` / `R_COVER=14`），
并用 `Stack` 包一层固定 46×46（`Image` 与 `LocalCoverImage` 混用时不至于让它撑开行高）。

### 1.3 底部回弹

官方《滚动组件通用接口 · edgeEffect》原文：

> `options`：组件内容大小小于组件自身时是否开启滑动效果……默认值：
> **List、Grid、WaterFlow 组件默认 `{ alwaysEnabled: false }`，Scroll 组件默认 `{ alwaysEnabled: true }`**。

`List` 的 `edgeEffect` 默认**是** `EdgeEffect.Spring`，但 `alwaysEnabled` 默认 **false**
⇒ 内容不满一屏（大屏 / 折叠展开 / 我的页本来就短）时拖到底没有回弹。
改法：`.edgeEffect(EdgeEffect.Spring, { alwaysEnabled: true })`。

### 1.4 「收藏歌单」那一段补回来

参考工程 `lxmusic-harmony` 的 `MineView`：`@State playlistTab` 卡头两段

* **收藏歌单的行**：封面 + 名字 + 平台·曲目数；**点击 = 打开「平台音乐」**

  在线歌单只有两条出路 —— 在平台音乐页里播放、或走 `NetworkImportSheet` 导入成本地歌单，

## 2. 追「标题下移」：把页盒顶边从"假设 0"改成"实测"

### 2.1 为什么上一轮的修法不够

上一轮把避让区那个"永久 0"修好了（`statusBarTopVp` 现在一定会是真实值），
但用户装上 `2116` 后**标题仍然下移** ⇒ 说明不是那个 0 的问题，而是**另一个未知量**：
**页盒（`HdsNavDestination` 的内容盒）在窗口里的顶边 y**。

两套量都依赖它，而它有两种可能：

| 盒顶 | HDS 标题栏（`avoidLayoutSafeArea: true` ⇒ 自己退回状态栏下方） | 内容层该让多少（目标是窗口 94 那条线） |
| --- | --- | --- |
| 0（贴屏幕顶） | 38..94 ✔ | 94 |
| 38（框架把盒子压在安全区内） | 38+38 = **76..132 ✗ 整条低一个状态栏** | 94−38 = **56**（写 94 就多让 38 ⇒「上方留白太大」） |

参考工程 lxmusic-harmony 是按"盒顶 = 0"写的（真机可用），我们照抄；
但我们这台机器显然不是 —— 所以**不能再假设**。

### 2.2 改法：`PageTopInsetHelper`（musicbasic，新增）

页根挂 `onAreaChange` 量一次 `newArea.globalPosition.y`（窗口坐标 vp），
由它推两个量（默认 `boxTopVp = 0` ⇒ 行为与老版本**完全一致**，不会回退）：

```ts
PageTopInsetHelper.contentOffsetVp(boxTopVp)      // = max(0, 状态栏 + 56 − 盒顶)
PageTopInsetHelper.avoidLayoutSafeArea(boxTopVp)  // = 盒顶 ≤ 0.5
```

* 内容让位：盒顶 0 → 94；盒顶 38 → 56 ⇒ 两种情况内容都落在窗口的 `38 + 56 = 94` 那条线上；
* 标题栏：盒顶已经在状态栏下沿时**不再**让 HDS 自己退（否则就是 38+38）。

落地到三处（用户点名的两页 + 二级页）：

| 文件 | 内容让位入口 | 标题栏选项 |
| --- | --- | --- |
| `SettingPage.ets` | 滚动内容根的 `padding.top` | `avoidLayoutSafeArea` |
| `RecordListPage.ets`（历史 / 收藏） | `titleTopInset()`（列表首个 `Blank()`） | `avoidLayoutSafeArea` |
| `SettingsDetailPage.ets` | `panelTopInset()` / `contentTopOffset()` / 音源面板首个 `Blank()` | `avoidLayoutSafeArea` |

标题栏选项是**有缓存**的（`cachedTitleBarOptions`），所以三页都加了
`@Monitor('boxTopVp')` 清缓存，量到非 0 后标题栏会跟着改。
日志标签 **`RzdPageTopInset`**：`boxTopVp=… offset=… avoid=… page=setting|record|settingsDetail`。
