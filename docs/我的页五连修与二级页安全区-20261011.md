## 5. 二级页：状态栏 / 标题栏 / 底下那条播放条

### 5a 状态栏与 HDS 标题栏（跨页归一，规则两条）
1. 二级页根节点（`HdsNavDestination`）必须有
   `.expandSafeArea([SafeAreaType.SYSTEM], [SafeAreaEdge.TOP, SafeAreaEdge.BOTTOM])`
   —— 官方《安全区域》：`expandSafeArea`「支持组件**在不改变布局情况下**扩展其绘制区域至安全区外」。
2. 二级页根节点上的 `.ignoreLayoutSafeArea(...)` **只允许 `BOTTOM`** —— 它会**改变布局**，
   根节点带 TOP 会把 HDS 标题栏顶进状态栏（用户看到的"标题跑到状态栏下面"）。
   需要"照片/Hero 铺到状态栏底下"的，**只让那个装饰层自己**带 TOP
   （工程里已有范本：`DetailImmersiveBackdrop` / `PlaylistImmersiveBackdrop`）。
* 逐页落实情况见交付说明（`RecordListPage` / `SettingPage` / `SettingsDetailPage` / `OnlineSearchPage` /
  `PlaylistsPage` / `PlaylistHomePage` / `PlaylistDetailPage` / `MusicRecognitionPage`）。

### 5b 底下那条悬浮播放条**透明** —— 是上一版自己把它关掉的
官方《组件适配沉浸光感》原文：「设置悬浮材质后，**不建议**再通过 `barBackgroundColor`、
`barBackgroundBlurStyle` 为 TabBar 设置背景色或背景模糊，**避免遮挡材质效果**。」
我们上一版照 2026-10-01 那次实验写了 `.barBackgroundColor(Color.Transparent)` +
`.barBackgroundBlurStyle(BlurStyle.NONE)` —— 结果**把 HDS 自己那条悬浮胶囊背板一起关掉了**
（真机现象正是"透明，只看得见封面和按钮"）。⇒ 两行**删除**，背板与材质全交给 HDS
（与首页那条官方底栏的做法一致：首页从来就没设这两个属性）。

**若真机上仍然没有胶囊背板**，下一步（唯一还没试的官方路线）：把宿主从"页签栏 = 播放器"
换成官方为音乐场景规定的 **`miniBar`** 路线（`barFloatingStyle.miniBar = { miniBarBuilder, enableMiniBarBackground: true }`），
见官方最佳实践《沉浸光感 · 沉浸式 MiniBar》：「在音乐播放场景中，采用**主 HdsTabs + 可折叠 MiniBar** 的组合方案」。
