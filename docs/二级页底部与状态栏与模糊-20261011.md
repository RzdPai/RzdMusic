# 二级页底部/状态栏/模糊（2026-10-11 第十九轮）

> 用户（附三张二级页截图）：
> 「1. 你看看现在二级页面的底部。2. 现在是内容啥的都在状态栏下面。3. 平台音乐页面没模糊效果。」

**验证等级：编译级 + 产物级（本机无设备）** —— 上屏观感未上机验证。

---

## 1. 二级页底部（播放条）

从三张截图看：**胶囊背板回来了**（上一轮"空 TabContent"那条修法生效）——
歌单详情 / 播放历史 / 播放队列页底部都是"一条深色胶囊 + 封面 + 播放/下一首/队列"。

但有个我自己写出来的毛病：**离底距离给了两遍** ——
`barFloatingStyle.barBottomMargin(...)` 给一次、宿主 `HdsTabs` 上又 `.margin({ bottom: ... })` 一次
⇒ 真机上播放条浮得偏高。
**改法**：删掉那个 `.margin({ bottom })`，只留 `barBottomMargin`（与首页那条官方底栏同一口径）。

## 2. 「内容啥的都在状态栏下面」

现象（截图）：**列表的行被画进了状态栏那一条** —— 时间/信号图标后面就是封面与文字
（往上滚的行一直画到屏幕 y=0）。

原因：内容容器（页根 `HdsNavDestination` 里承载 `List`/`Scroll` 的那一层）**从屏幕 y=0 起排**，
于是列表可以滚到状态栏里；页根虽然用 `expandSafeArea(TOP)` 把**页面底色**铺到了状态栏，
但内容层没有被挡住。

**改法（每页一行，规则统一）**：给**内容容器**加 `.padding({ top: getStatusBarTopVpFromWindowUtil() })`
（让开状态栏高度）。里面的 `List` 本来就有 `clip(true)` ⇒ 行再往上滚最多滚到**状态栏下沿**为止；
标题栏那 56vp 仍是透明的，列表照样从它底下穿过（**沉浸式不受影响**，用户要保留的就是这一段）。
页根的 `expandSafeArea(TOP)` + `backgroundColor` 继续负责把页面底色铺到状态栏那一条。

* 本页改的：`RecordListPage`（播放历史/收藏，截图那一页）、`SettingsDetailPage`（设置各子页；
  宽屏内嵌那一支不加，由外层大设置页负责）。
* 其余列表型二级页（全部歌单 / 歌单首页 / 歌单聚合 / 播放队列 / 本地音乐 / 听歌识曲 /
  在线搜索 / 同步设置 / 云端曲库）同一规则一并改（清单见交付记录）。
* **不适用**：整页就是一张大图的 `PlaylistDetailPage` / `ArtistDetailPage` / `AlbumDetailPage` ——
  状态栏那一条本来就是照片（用户明确要过"歌手页顶部要是歌手照片"），不许盖。

## 3. 平台音乐页面没模糊效果 —— 根因：**滚动容器没接上标题栏**

HDS 标题栏的"滑过才渐变模糊"是靠 **标题栏 ← 滚动容器** 的绑定驱动的：
`SettingsDetailPage` 根节点有 `.bindToScrollable([this.pageScroller])`，
而它渲染平台音乐时写的是 `PlatformMusicPage({ onClose })` —— **没把 `pageScroller` 传下去**，
于是 `PlatformMusicPage` 用它**自己 `new` 的** `Scroller` 去包 `Scroll`（`@Param pageScroller` 的默认值）
⇒ 它滚它的、标题栏收不到滚动量 ⇒ 永远不模糊（材质在，缺的是那一整段渐变模糊）。
同一个文件里 `SettingsDetailPage` 自己的列表就没事，正因为它用的就是被绑定的那个 scroller。

**改法**：`PlatformMusicPage({ pageScroller: this.pageScroller, contentTopOffset: this.contentTopOffset(), onClose })`。
（顺带把 `contentTopOffset` 也传上——原来默认 0，面板顶部会顶到标题栏底下。）

## 4. 真机首查

1. 二级页底部那条播放条：**离底距离应和首页那条底栏一个档**（不再偏高），胶囊背板与光感都在；
   `findstr RzdSecondaryMiniMaterial` 应打 `mode=hds-systemMaterialEffect officialRegion=yes tabContent=nonEmpty`。
2. 播放历史 / 设置 / 音源管理 / 全部歌单…：**状态栏那一条只有页面底色**（时间图标后面不再有封面/文字），
   但列表**仍能从标题栏底下穿过去**（往上滑看渐变模糊）。
3. 平台音乐（我的 → 平台音乐）：列表往上滑时**标题栏出现渐变模糊**（与歌单详情同款）。
