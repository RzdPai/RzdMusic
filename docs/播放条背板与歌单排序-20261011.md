## 1. 播放条没有胶囊背板 —— 找到第二个原因

上一轮（§27.6）只解决了"我们自己把栏体背景关掉"那一半：删掉了
`barBackgroundColor(Color.Transparent)` + `barBackgroundBlurStyle(BlurStyle.NONE)`。这轮找到另一半：

**`TabContent()` 是空的。** 宿主写的是
```
HdsTabs { TabContent() { } .tabBar(播放器) }
```
空的 TabContent 让 HDS 认为这条栏没有内容 ⇒ **不画悬浮胶囊背板**（材质也就没有承载）。
旁证很硬：**2026-10-01 那次实验就是"空 TabContent + 自绘背板兜底"** —— 作者当年就撞上了同一个现象，
只是用自绘背板把症状盖住了，所以这次回退代码里只留下"为什么需要背板"的注释。

本轮改法（`products/default/src/main/ets/pages/Index.ets` 的 `floatingMiniBar()`）：
1. `TabContent() { Column().width('100%').height('100%') }` —— 给一个**真实满尺寸**的内容；
2. `barFloatingStyle` **只留首页那条官方底栏用过的键**：
   `{ barBottomMargin, adaptToHandedness: false, systemMaterialEffect: ambientTitleMaterial() }`；
   实验那套 `barWidth` / `barSideMargin: 0` / `gradientMask: { maskColor: Transparent, maskHeight: 0 }`
   **全部删掉**（它们是配那块自绘背板用的，而且会和 HDS 的让位动画打架）；
3. 播放器内容改 `.width('100%')`（栏宽交给 HDS，不再写死 `floatingMiniBarWidthVp()`）；
4. 顺手删掉不再使用的 `floatingMiniBarWidthVp()` / `floatingMiniBarSideMarginVp()` /
   `FLOATING_MINI_BAR_MAX_WIDTH_VP`（"栏要么贴边、要么撑成大长方形"就是自己算宽度造成的）。

**若真机仍无背板**：剩下唯一没试的官方路线 = 《沉浸光感 · 沉浸式 MiniBar》
（`barFloatingStyle.miniBar = { miniBarBuilder, enableMiniBarBackground: true }`，主 HdsTabs + 可折叠 MiniBar）。

## 3. 歌单页：菜单按钮 + 排序

* **"菜单按钮没了"的真因**：旧代码在**排序模式**下会把行尾的 ⋯ 按钮**换成拖动手柄**；
  而排序模式进去后很难退出（要点头题栏那颗「排序」→「完成」），所以用户看到的就是
  "菜单按钮消失 → 无法删除/重命名/导出"。
* **改法（照用户要求）**：
  1. **排序模式整套删除**（`playlistSortMode` / `enterPlaylistSortMode()` / `exitPlaylistSortMode()` 全删）；
  2. 标题栏菜单**只剩「+」**（新建 / 导入）—— 排序按钮消失；
  3. ⋯ 按钮**永远都在**（导出 / 设置歌单封面 / 移除自定义封面 / 重命名 / 删除）；
  4. **长按行直接拖**（`List` + `Repeat.onMove` 本来就是长按拖动），拖动落到 `movePlaylist()`，
     它**立刻** `MusicStoreService.reorderPlaylists(ids)` 落库
     ⇒ 松手后再也不会被后续 `playlistVersion` 刷新冲回原顺序（用户报的"松手之后位置还是原来的"）。

## 4. 「标题 / 状态栏那条」的现状（要说实话）

从用户这张截图看：标题「音源管理」在状态栏**下沿之下**、状态栏那一条是**页面自己的底色**
（没有透出上一页）—— 也就是上一轮那两条修法在**这一页**是生效的。

结论：**无法从现有证据定位第 1 条的"标题/状态栏"具体指哪一页**。全仓还有 4 个二级页
**完全没有 safe-area 属性**：`SongPage` / `PlaybackPageRoute` / `PlaylistHubPage` / `SongQueueListPage` ——
它们都是 `NavDestination()` + `hideTitleBar(true)` 的**手表向**页面（`watch_page_background`），
本轮**故意没动**（动它们会改观感，且它们没有 HDS 标题栏）。
