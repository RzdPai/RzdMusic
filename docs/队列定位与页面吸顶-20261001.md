# 队列定位与歌手歌单吸顶

## 当前需求
当前播放队列半模态列表铺到底+定位当前；歌手增加播放全部，图片上滑收起；歌手/歌单播放全部行滚过hero后吸顶（在HDS标题下），歌手专辑/最新/最热筛选行也吸顶。

## 当前实现
QueuePlaylistSheet删除外24vp bottom padding与List16vp contentEndOffset，内容height100%+List layoutWeight填完整模态body，不切全window。标题新增定位当前按钮，Scroller.scrollToIndex(selectIndex,true,CENTER)原地滚动不换曲。点击队列歌曲改PlaybackIntent由壳dispatch，去直接MediaService.loadAsset入口，remove仍复用service队列逻辑。

歌手单List首Hero随滚动收起，后GroupHeader包括playall(歌曲tab)与专辑/最新/最热切换；HDS MINI官方56vp占位，body有界calc100%-56vp，sticky在标题下。playall当前sort已加载真实数组（每次分页50），标签明确已加载不是全作品，不自动抓所有页。歌单两branch单有界List首Hero+GroupHeader播放全部，常态LazyForEach稳定key；customdrag保持Repeat.onMove置group，嵌套拖动交付设备未验，filtered/sorted点击映射正确VM源index。Hero/covertransition/navback不改，mini避让底offset保留。长列表必须LazyForEach稳定key，单List滚动+ListItemGroup stickyHeader优先，不外Scroll使懒加载失效，不更导航/covertransition/mini底距。

均衡器与音效仅分析完成，详见 `均衡器音效可行性分析-20261001.md`。轻量AVPlayer默认/关音效可接；真正10段EQ正式AudioSuiteAPI22支持，但需解码PCM/AudioRenderer双backend，不是AVPlayer属性。无音效代码修改，无音效依赖/权限新增。
