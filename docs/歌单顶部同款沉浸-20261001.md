# 歌单顶部同步歌手沉浸

## 范围
用户仅歌单页顶部改同最新歌手：状态栏照片延伸，mask puretransparent→opaque主题取色，标题初透明上滑不透明。保留Hero shared covertransition、播放/收藏/分享、Builder父箭头capture、单boundedList/Group sticky/lazy、mini/batch安全距、多形态分支。不改artist/album/Queue/字体/download，不新增windowfullscreen。

## 施工
歌单模块不能反向import setting DetailImmersiveBackdrop，featurelocal同模式Backdrop；decor matchParent/TOPignore/HitTestNone，photoheighthero+56+statusBarTopVp，currentOffset yOffset单位vp直接用，不px误换。标题BlurDISABLE20/MaterialNONE23guard，HDS original背景transparent→scroll取色opaque，前景仍safe title56且sticky就在标题下。实际Hero源image100%×320vp且sharedid在整幅封面（不是小方），为保转场几何不改160方、不移id、不强opacity0。最低风险保可见原image，仅原150vp渐变改全320vptransparent→avg1；独立decor延status/title，前景Hero重叠区域仍原照片，衔接采样需要真机看。两branch均同in-flowList首Hero并非PC固定左Hero，因此decor随同pageScroller的yOffset，Section最小Event转发onDidScroll父更新，不能一个scroller再绑定第二List。
