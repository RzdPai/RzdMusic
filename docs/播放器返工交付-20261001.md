# 播放器透明/底白/重复实例与文字连续转场返工

## 用户实测与本轮改动
上轮09:45包编译/符号成功不能证明视觉；用户实测二级条无背板、play底白、动画三份条，本轮据反馈返工。

1. 二级条：保留HDS End浮动单可见bar，但移除42vp宿主clip、取消barOverlap引入的普通thick blur（显式NONE/透明bar）。下层独立同胶囊半透明backing+outline，不给前景内容opaque/blur遮材质。不称此保底背板就是沉浸光感，真设备效果需再验。强度仍同AmbientState。
2. 底白：官方ignoreLayoutSafeArea非matchParent只移动不增尺寸，100% overlay上移却安全区高度未扩。本轮default/pc overlay及default clone局部width/height LayoutPolicy.matchParent+ignoreTOPBOTTOM，不扩root、不移动底层HDS、不重新toggle全窗口。控件仍padding系统栏，背景在外。RzdPlayerViewport记录overlay与window/系统top/nav bottom。
3. 单实例所有权：sourceBarHidden共享V2门，动画开始源HomeMiniBar根Visibility.Hidden保留锚点量测不卸载，二级HDS背板+内容整个外Stack同门；主页仅关miniBar background不关4tabs。shell按钮clone isMorphClone:true/metaOpacity0，防文字重复及id重复，不受源门祖先隐藏。取消/收尾恢复源，展开态不留源可见，收起落位才交还。
4. 歌名歌手续飞：单MorphMetaBridge读真实源/目标两Text量测及font/baseline，冻结端点后与封面同morphP连续插值位置/宽高/fp/基线/行高。首页/二级源用独立浮动ID，secondary不跟homeExpanded保持42vp。源/目标文字交接由共同state门，不再旧meta淡出+目标淡入叠两套。缺实测端点不杜撰位置，日志标fallback，不阻封面动画/源隐藏；PC无mini文字端点目前诚实fallback无文字飞，不虚构。换曲取消旧文字桥不reset封面/歌词。字体family/weight/color及maxLines为中点离散交接，长标题两行重排与手势真机待验；不能称所有字体属性均连续插值。AMLL及其它歌词动画不改。
5. 搜索其它版本：用户追加后明确独立bindSheet半模态，不跳现OnlineSearch页。复用现lxSearch聚合，关键词当前title+singer可调整，结果点击替换当前queue槽位+PlaybackIntent pendingQueueIndex立即播放，保持其它队列与播放器打开，异步搜/取消/换歌身份保护。
