# 播放器浮层 Back 路由保护（2026-10-01）

## 实施

- 新增 `common/musicbasic/src/main/ets/util/PlayerBackGuard.ets`：`guardPlayerBack(source)` 在事件发生时连接唯一共享 V2 `MusicAppState` 和 `PlayerExpandState`；播放器 `isShowPlay`，或 `preparing / animating / pullDragging / morphLive()` 任一为真时，调用 `requestCollapse()` 并返回 `true`。
- `morphLive()` 包含 ENTERING（含量测等待）、LEAVING、LANDING，故动画/pending 期间返回不穿透下层栈。没有播放器/形变活动时返回 `false`，保持系统原生默认返回。
- common Index 精准增加一个导出，不覆盖并发新增 CoverCache 导出。
- 18 个 feature 文件的 19 个 HdsNavDestination/NavDestination 实例均显式绑定，SplitColumnPlaylistPage 包括 HDS 与原生两个分支。
- PlaylistDetailPage 已有回调的第一项为 guard；未消费时仍调用原 `interceptPlaylistBack()`，原 batch/search/返回转场逻辑不变。
- 不操作任何 NavPathStack，不 push 播放器路由、不 pop 后恢复路径快照、不重建 params/滚动状态；不依赖某页的 local pathStack。因此推荐/设置/本地音乐等不同导航栈均走同一判据。
- 未修改 products/default 或 products/pc Index，未修改 sync UI、MiniBar 或设置缓存清理实现。无新增依赖或权限。

## 官方 MCP 依据

- [NavDestination onBackPressed](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-navdestination#onbackpressed10)：与 Navigation 绑定的导航控制器中存在内容时生效；true 重写返回键逻辑，false 回退上一个页面。
- [HdsNavDestination onBackPressed](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ui-design-hdsnavdestination)：与 HdsNavigation 绑定的页面栈存在内容时生效，true 重写返回、false 回退；不推荐同时设置返回键自定义事件与 onBackPressed。
- [侧滑拦截官方指南](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/custom-dialog-select-develop)：物理返回按钮或手势滑动触发 NavDestination.onBackPressed，true 可实现侧滑拦截。
- [Navigation](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-navigation)：页面栈由 NavPathStack 控制。
- [自定义组件生命周期](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-custom-component-lifecycle#onbackpress)：Entry 的 onBackPress 仅为 router 路由页面回调。本次不依赖壳 Entry 的回调拦住下层 Navigation，直接在每个 destination 原生返回入口消费。

本次 MCP 文档未检出明确列举“Navigation 相对 Entry onBackPress 的分发优先级”文字，不把推断写成官方原句；采用 destination 事件入口是避免依赖该优先级的实现。未使用 AttributeModifier 自动绑定：当前官方 NavDestination.onBackPressed 条目没有声明 modifier 支持，且自动覆盖既有回调易破坏歌单返回语义，显式绑定更易审计。
