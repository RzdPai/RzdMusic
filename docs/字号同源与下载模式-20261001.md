# 字号同源与下载音质模式

## 本轮用户
音质UI回最初顺序：基础音质标题/基础档位→拓展关开→开启时拓展档位，删除基础括号和拓展说明标题。下载设置新增跟随默认/手动。文字动画终点字号!=正常字号，不能继续靠改clip掩盖。

## 源码依据
player float资源 title_font_play=20vp、title_font_play_md=30fp、font_fourteen=14fp。官方getNumber9已确证：带vp或fp的float结果返回px，此前publishMeta把px裸当fp，真实Text.fontSize(Resource)却正确解析，因此clone终点字体被额外density放大。https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-resource-manager#getnumber9 。这不是再次猜裁剪。改两者共用canonicalnumberfp，20vp经vp2px→px2fp保尺寸、30/14fp明确fp；panel24/22fp，普通/compact/md同一branchhelper声明字体。

下载模式持久follow/manual，手动档位8档，explicit调用档位优先；otherwise manual选档或current network default。单/批量入队requestedQuality一经snapshot不随后续设置变化。备份schema加入两个key，缺省follow。批量PlaylistBatchActionBar此前绕DownloadUtil直接enqueueBatch，纳入同resolver防忽略模式。审计发现现有多数菜单下载均显式档位sheet，新设置不能仅添加resolver无人使用，须添加“按下载设置”入口传空走模式，同时保留显式档位最高优先。
