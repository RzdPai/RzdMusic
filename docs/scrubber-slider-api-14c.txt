trackThickness(value: Length)：设置滑轨粗细，会影响滑块大小。
设定值小于等于0或大于滑动条宽高时取默认值。
blockSize(value: SizeOptions)：设置滑块大小；设置宽高之一小于等于0时取默认值。
sliderInteractionMode 默认 SliderInteraction.SLIDE_AND_CLICK，鼠标或手指按下即发生移动。
