# 歌单歌曲 HTTP 封面缓存

## 改动

- `common/musicbasic/src/main/ets/services/CoverCacheService.ets`：单例异步专目录缓存服务与 V2 generation/bytes/clearing 状态。
- `common/musicbasic/src/main/ets/components/LocalCoverImage.ets`：显式 `cacheHttp` 参数，保持其它调用网络图片原行为；歌单 HTTP 缓存通过既有本地 PixelMap 路径显示；异步 open/close，缓存图片解码限制 256px。
- `common/musicbasic/src/main/ets/components/CoverCacheSettingsCard.ets`：共享设置入口、大小统计、二次确认、实际完成/失败提示。
- `common/musicbasic/Index.ets`：导出服务、状态、设置卡片。
- `features/playlist/src/main/ets/view/PlaylistDetailSongListSection.ets`：歌曲行封面复用 LocalCoverImage；原 Repeat 和稳定 key、排序逻辑不变。
- 两设置页 `SettingPage.ets` / `SettingsDetailPage.ets`：仅 OtherSheet 加卡片与 import。

## 安全与并发约束

1. 只接收 HTTP/HTTPS 封面，完整 URL UTF-8 SHA256 作为稳定磁盘键，既不将 URL 落盘也不打敏感 URL/error message 日志。文件在 `context.cacheDir/rzd-http-covers-v1`；清理不涉及下载歌曲、filesDir、云备份、账号或歌单。
2. 100MiB 上限、1024 项上限、7 天固定写入 TTL（非刷新命中 TTL）。写前淘汰旧项预留容量，启动/统计也清过期与遗留 partial。
3. 并发 2；按 URL 去重；排队最多 64，不遍历歌单预下载，队列满保留占位，下一次组件出现/源变更可重试。列表渲染结构不改变。
4. HTTP 200、ARRAY_BUFFER、maxLimit 4MiB、非空、最大尺寸 8192px，实际解码 128px 校验有效图片；无需猜测不可靠服务端 MIME。下载失败占位，不回落到无界第二次网络请求。
5. 所有磁盘扫描/stat/open/write/fsync/close/rename/unlink 均异步；磁盘操作串行锁，网络仍并发 2。完整写 `.partial`，fsync/close 后同目录 rename 才提供最终路径。
6. clear 先 clearing + generation 递增；停止接收新任务/取消排队/等待 active settle；旧任务每个关键边界检查 generation。磁盘锁确保 rename 与 clear 无乱序，最后真实统计为 0 才提示完成；失败抛出并提示未完成。组件 generation 清旧路径/位图且不自动重新下载，陈旧解码不再加入内存 Map。
7. 零第三方依赖、零新增权限；common 无上层 import。不修改 PlayerExpandState、路由或播放真源。
