# 二级 mini 真正 HDS 材质承载

## 当前实现

`products/default/src/main/ets/pages/Index.ets` 的 `floatingMiniBar()` 使用单页 HdsTabs。
唯一可见 CustomBuilder tabBar 是原 HomeMiniBarPlayer；不设置额外 miniBar，不创建圆点，不隐藏透明页签。
空 TabContent 仅满足 Tabs 的公开子组件结构，不承载内容或交互。没有新增第二条栏。

- 宿主宽度沿用 floatingMiniBarWidthVp，固定高度42vp、原底部间距和21vp圆角。
- barHeight42、barSideMargin0、barBottomMargin0、gradientMask高度0。
- scrollable false、animationDuration0，不引入页间滑动。
- 真实 barFloatingStyle.systemMaterialEffect 使用与主页一致的 AmbientState：0 ADAPTIVE/ADAPTIVE，1 IMMERSIVE/SMOOTH，2 IMMERSIVE/GENTLE，3 IMMERSIVE/EXQUISITE。
- 不重复保存主题或材质偏好，不叠普通blur、不绘制shader。
- 原条件渲染、外层Transparent、播放器锚点、点击/上拉、主页Tabs和导航结构保持。

## 排查与验证边界

日志grep：`RzdSecondaryMiniMaterial`。
`mode=hds-systemMaterialEffect singleVisibleBar=true` 标识真正材质承载，`host width=... height=42 level=...`核对胶囊尺寸。
编译由父agent统一执行。当前没有设备，必须上机核对HDS内部栏padding、封面/按钮是否完整、点击控制区与上拉是否被Tabs内部手势影响、背景深浅与四档材质、形变量测锚点。
不把编译通过等同于真机视觉和交互验收。
